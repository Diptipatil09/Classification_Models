
# Practical No. 4: Classification Models

## 1. Project Title
**Classification of Iris Flowers Using Machine Learning Algorithms**

## 2. Problem Statement
To implement and compare four classification algorithms — Support Vector Machine (SVM), Decision Tree, K-Nearest Neighbors (KNN), and Naïve Bayes — using the Iris Flower Dataset. Evaluate their performance using accuracy, precision, recall, F1-score, and log loss.

## 3. Objectives
- To understand the working of different classification algorithms.
- To train and test classification models using the Iris dataset.
- To evaluate and compare model performance using standard evaluation metrics.

## 4. Dataset Description
The Iris Flower Dataset is a built-in dataset available in Scikit-learn. It contains 150 flower samples belonging to three species.

**Features:**
- Sepal length
- Sepal width
- Petal length
- Petal width

**Target classes:**
- Setosa
- Versicolor
- Virginica

The dataset contains 150 samples and 4 numerical features. Each sample belongs to one of the three flower classes.

## 5. Algorithms Used
1. **Support Vector Machine (SVM):** Finds an optimal decision boundary to classify data.
2. **Decision Tree:** Classifies data using a tree of decision rules.
3. **K-Nearest Neighbors (KNN):** Predicts a class based on the nearest training samples.
4. **Naïve Bayes:** Uses Bayes' theorem with an assumption of conditional independence between features.

## 10. Model Evaluation Metrics

- **Accuracy:** Measures the proportion of correctly classified samples.
- **Precision:** Measures how many predicted positive classifications are correct, aggregated here using weighted averaging.
- **Recall:** Measures how many actual samples are correctly identified, using weighted averaging.
- **F1-score:** The harmonic mean of precision and recall.
- **Log loss:** Evaluates the quality of predicted class probabilities. Lower values are generally better.
